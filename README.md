# School Management System

A beginner-friendly School Management System built with Python. This project manages basic student and teacher information using JSON files for data storage.

## Features

### Student Management

* Search students by ID
* Add new students
* Print all students
* Search students by name
* Delete students
* Update student information
* Search students by class
* Show active and inactive students
* View school and class statistics

### Teacher Management

* Search teachers by ID
* Add new teachers
* Print all teachers
* Search teachers by name
* Delete teachers
* Update teacher information
* Show active and inactive teachers
* Search teachers by subject

### Academic Information

* Update student marks
* Show student results
* Calculate grades

### Attendance Management

* Update student attendance
* Show student attendance
* Find students with low attendance

### Fees Management

* Find students with unpaid fees

### School Reports

* View overall school statistics
* View total and active students
* View total and active teachers

## Technologies Used

## How to Run

### 1. Install Python

Make sure Python is installed on your computer.

You can check it by running:

```bash
python --version
```

### 2. Download or Clone the Repository

Clone the repository using:

```bash
git clone https://github.com/HafizHussainAli/School-management-system.git
```

Then move into the project folder:

```bash
cd School-management-system
```

### 3. Run the Program

Run:

```bash
python flagshipschoolmgnt.py
```

The program will display a menu with different options for managing students, teachers, attendance, marks, fees, and school statistics.
